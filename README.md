# Cosmic Compass

Build a Retrofuturist asteroid tracker , that  uses NASA's asteroid tracking data to visualize incoming objects from space plus 15000 active satellites starlink swarms gps constellations the international space station (use nasa api to pull live data) --I want to make a near earth encounter system visualiser. The aesthetic is retro futuristic like the inspiration images. It should be a web app, WebGL, and draw upon live data from public NASA APIs (https://api.nasa.gov/⁠�) and JPL APIs (https://ssd-api.jpl.nasa.gov/⁠�) to show the Earth / Solar System and the various things flying around it. it should track asteroids, satelites,solar wind and spacecrafts pulling live from nasa public databases .. like Star Wars/ evangelion interface
